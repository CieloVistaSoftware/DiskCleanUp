Windows Service Architecture

DESIGN v2.1 · 2026-03-01

Mark Russinovich's Sysmon is one of the most powerful system monitoring tools ever built — kernel-level hooks, zero missed events, battle-tested in enterprise security. But its interface is XML config files and Event Viewer.

DiskCleanUp decorates that raw power with a beautiful, accessible web dashboard — real-time scan results, color-coded file types, one-click cleanup, animated progress. Sysmon is the engine. We're the windshield.

02

The Four Players

⚡

Sysmon Kernel Driver

Russinovich's ETW hooks capture every file create/delete/rename at the kernel level. Filtered to scan roots only. ~0.1% CPU. Events persist in Windows Event Log — survives everything.

⚙

DiskCleanUp.Service

Windows Service on port 5100. Owns all business logic, scan orchestration, JSONL cache, config, keep-list. Subscribes to Sysmon events. Starts on boot, survives logoff.

🔔

DiskCleanUp.Tray

System tray icon. Polls service health every 10s. Right-click for service controls. Double-click opens dashboard. Starts on user login. Killing it doesn't stop the service.

🌐

Browser Dashboard

Your existing wwwroot/ — HTML, JS, CSS. Served by the service itself on :5100. Zero code changes needed. WebSocket for live events, REST for data. Opens and closes freely.

Migration Plan

📁

Phase 1: Restructure

New solution structure, same behavior. Split Program.cs, move to %ProgramData%, data migration script. Test gate: 148 tests pass.

⚙

Phase 2: Windows Service

UseWindowsService(), CLI install flags, EventLog logging, recovery policy. Test gate: starts on boot, scans run in background.

🔔

Phase 3: Tray App

WinForms NotifyIcon, health polling, service controls, auto-start on login. Test gate: tray shows status, controls work.

⚡

Phase 4: Sysmon + Polish

SysmonWatcher, delta scans, activity feed, targeted area scans, toast notifications, installer. Test gate: real-time cache updates.

🔒

Security

Kestrel binds localhost only — zero external attack surface. Path validation via AllRoots(cfg) prevents arbitrary file ops. No auth needed for localhost IPC.

📦

Deployment

Phase 1-3: zip + PowerShell install script. Phase 4: MSI/MSIX installer with proper ACLs, registry entries, and service registration.

🔮

Future

Named Pipes for local IPC. Toast notifications. Scheduled scan profiles. OneDrive/Google Drive integration. Multi-user dashboards. Remote LAN access with auth.
